# QA Mobile Testing Portfolio

Projeto de demonstração de fundamentos de Quality Assurance (QA) para aplicações Android.

## Objetivo
Demonstrar conhecimentos em planejamento de testes, elaboração de casos de teste, documentação de defeitos, automação de testes com Appium e organização ágil.

## Aplicação sob teste
**Sauce Labs My Demo App — Android**

## Tecnologias e ferramentas
- Python & Pytest
- Appium Server / Python Client
- Git e GitHub
- Metodologia Ágil (Kanban)

## Escopo inicial
Validar o fluxo de seleção de um produto, adição ao carrinho e conferência do item.
