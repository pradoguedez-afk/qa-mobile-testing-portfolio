# Caso de Teste — Adicionar produto ao carrinho

**ID:** CT-MOB-001  
**Tipo:** Teste funcional  
**Prioridade:** Alta  

## Objetivo
Verificar se um produto selecionado no catálogo pode ser adicionado ao carrinho com sucesso.

## Passos
| Nº | Ação | Resultado esperado |
|---|---|---|
| 1 | Abrir o aplicativo | Tela inicial do catálogo é exibida corretamente. |
| 2 | Selecionar o primeiro produto do catálogo | Detalhes do produto são carregados. |
| 3 | Clicar no botão "Add to Cart" | O ícone do carrinho atualiza o contador para "1". |
| 4 | Clicar no ícone do carrinho | O usuário é direcionado à tela do carrinho contendo o item. |

## Resultado Esperado Final
O produto selecionado aparece listado corretamente no carrinho de compras.
